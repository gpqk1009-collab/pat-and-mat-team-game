# Play Mode 검증 체크리스트

이 문서는 수행 지침이다. 체크가 완료된 결과표가 아니다. Unity에서 실행 후 결과를 기록한다.

## 환경

Unity 버전: ______ / 렌더 파이프라인: ______ / Input System: ______
해상도와 화면비: ______ / 목표 FPS: ______ / 실행일: ______

## 컴파일과 셋업

- [ ] 컴파일 오류 0개. 기존 프로젝트의 오류와 키트 오류를 구분.
- [ ] Create Prototype Scene 실행 후 씬/재질/4개 레이어 생성.
- [ ] 재실행해도 기존 씬/재질을 덮어쓰지 않음.
- [ ] Run Ammo Ledger Self Tests 성공 로그 확인. 이 테스트는 물리/카메라 검증이 아님.
- [ ] URP에서 분홍색 오류 재질 없음. 기본 카메라가 1개이며 AudioListener 중복 없음.

## 입력과 이동

- [ ] WASD가 카메라 수평 축 기준으로 동작.
- [ ] 대각선 이동이 직선 이동보다 빠르지 않음.
- [ ] Shift 달리기. 조준 중에도 Shift를 누르면 달리기.
- [ ] Esc 후 클릭이 바로 발사하지 않고 조작 복귀에 사용됨.
- [ ] Tab 전환 후에도 우클릭이 항상 조준 해제/회수로 동작.
- [ ] 자유 커서 모드에서 가운데 버튼을 누르고만 카메라 궤도 회전.

## 슬라이딩

- [ ] 왼쪽으로 이동하면서 오른쪽을 조준한 뒤 Space → 오른쪽으로 슬라이딩.
- [ ] 슬라이딩 도중 커서를 바꿔도 처음 방향 유지.
- [ ] 공중에서 새 슬라이딩을 시작하지 않음.
- [ ] 벽을 향한 슬라이딩이 벽을 통과하지 않음.
- [ ] 낮은 통로 아래에서 종료해도 머리가 천장을 뚫지 않음.
- [ ] 통로를 벗어나면 높이가 정상 복구.
- [ ] 30/60/120 FPS에서 속도와 지속시간 비교. 프레임 경계에 따른 작은 차이는 측정 기록.

## 조준/발사

- [ ] 첫 좌클릭: 카메라 조준 연출만 발생, Ammo 6 유지.
- [ ] 두 번째 좌클릭: Ammo 5, 발사체 1개.
- [ ] 마우스 버튼 유지: 추가 발사 없음.
- [ ] 여섯 발 이후 추가 클릭: 일곱 번째 발사 없음.
- [ ] 총구가 벽 옆에 있을 때 반대편에서 탄환이 생성되지 않음.
- [ ] 조준한 적의 이름과 체력이 화면 오른쪽에만 표시되고 머리 위 숫자는 없음.
- [ ] 적 피격은 오른쪽 체력 감소로 확인. 필요하면 PrototypeHUD의 Show Hit Counts를 켜 일반/회수 피격 카운트 확인.
- [ ] 커서를 다른 적으로 이동하면 대상이 바뀌고 벽/빈 공간/죽은 적/조준 해제에서는 패널이 사라짐.
- [ ] PrototypeHUD의 Texts 문구와 각 적의 Display Name을 수정·저장한 뒤 다시 Play해도 유지됨.
- [ ] Space에서 모델이 낮아지고 기울어지며 종료하면 원래 자세로 돌아옴. 물리 캡슐은 기울어지지 않음.
- [ ] 근거리/원거리/카메라가 벽에 붙은 상태에서 조준점과 충돌 위치 비교.

## 회수

- [ ] 1발만 발사 후 우클릭: 조준 해제와 조기 회수.
- [ ] 6발 소모: 0.25초 뒤 자동 회수, 조준 유지.
- [ ] 회수 중에는 일부 장전돼도 발사되지 않음.
- [ ] 탄환 도착 시에만 탄수 증가, 최종 6/6.
- [ ] 회수 중 우클릭 연타로 탄수가 7 이상 되지 않음.
- [ ] 회수 중 이동/Shift/Space 가능하고 탄환이 최종 위치를 따라옴.
- [ ] 우클릭 조기 회수 완료 후 첫 좌클릭은 다시 조준만.
- [ ] 자동 회수 완료 후 좌클릭은 바로 1발 발사.
- [ ] 허공 발사와 맵 밖 발사에도 탄환이 영구 유실되지 않음.

## 관통/중복 방지

우선 적이 없는 쪽으로 탄환을 배치하고, 플레이어가 이동해서 탄환과 플레이어 사이에 표적이 들어가도록 한 뒤 우클릭한다. 단순히 정면 표적만 계속 쏘면 탄환이 첫 표적 앞에 떨어져 후방 표적 관통을 시험할 수 없다는 점에 유의한다.
현재 피격 횟수는 Show Hit Counts를 켠 뒤 해당 적을 조준해 오른쪽 패널에서 확인한다.
아래의 RET는 한국어 기본 문구 '회수 피격'에 해당한다.

- [ ] 회수 탄 1발이 나란한 표적 여러 개를 지나면 각각 RET가 1 증가.
- [ ] 중간 벽이 있어도 그 뒤 표적이 회수 피해를 받음.
- [ ] 한 적에 자식 콜라이더를 추가해도 탄 1발당 회수 피해 1회.
- [ ] 회수 속도를 낮춰 오래 겹쳐도 같은 탄환의 피해 반복 없음.
- [ ] 탄 2발이면 같은 적에게 2회 피해가 가능.
- [ ] 회수 시작 시 이미 표적 콜라이더와 겹쳐도 타격.
- [ ] F2로 적탄 발사를 켜고 회수 경로에 겹치는 적탄 제거 확인.

## 카메라와 표시

- [ ] 탄환 1~3발을 멀리 발사한 뒤 우클릭하면 실제 회수 동안 가볍게 흔들림. 표적을 추적하기 편한지 확인.
- [ ] 6발 소모 후 자동 회수에서도 흔들리고 조준 유지. 자동 회수 대기 시간에는 회수 흔들림 없음.
- [ ] 회수 경로에 적을 놓아 맞히면 회수 중의 지속 흔들림보다 강한 명중 충격이 발생.
- [ ] 처치 타격에도 충격 발생. 같은 적의 여러 콜라이더에서는 탄환당 1회만 발생.
- [ ] 마지막 탄환 도착 후 지속 흔들림이 해제되고 충격도 설정 시간 안에 가라앉음.
- [ ] Motion Scale 0에서 회수와 명중의 화면 흔들림도 꺼지고 피해·회수·장전은 유지.
- [ ] 격한 화면 피드백 중에도 마우스 입력이 같으면 논리 조준 대상에 추가 흔들림이 섞이지 않음.

- [ ] 조준 진입 시만 강한 이동/기울기 연출, 발사 시 짧은 흔들림.
- [ ] 조준/해제 30회 반복 후 기본 각도에 누적 오차 없음.
- [ ] motionScale 0에서 펀치/흔들림이 꺼짐. 줌은 유지되는 것이 현재 규칙.
- [ ] 자유 커서의 조준 전환 도중 FOV 변경이 표적 선택에 미치는 영향을 기록.
- [ ] 창 크기 변경과 화면비 변경 후 커서/중앙 조준 광선 확인.
- [ ] 30/60/120 FPS에서 흔들림과 전환 감각 비교.

## 알려진 범위 제한

카메라 ray는 perspective 카메라의 pixelRect를 기준으로 계산한다. 렌더 텍스처, XR과 복수 플레이어 입력은 검증하지 않았다.
회수 탄환과 적탄은 같은 프레임의 상대 이동 경로로 교차를 판정한다. 현재 테스트 대상은 정지 표적과
직선 투사체다. 정식 이동형 적, 순간이동, 곡선 투사체를 추가하면 별도 연속 충돌 검증이 필요하다.
실제 출시용 화면 효과와 타격 판정은 별도 성능/접근성/플레이 테스트가 필요하다.
