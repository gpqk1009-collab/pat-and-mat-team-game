# Pretty Genocide prototype — project instructions

이 파일은 프로젝트 루트의 AGENTS.md로 사용하거나 기존 규칙에 합칠 초안이다. 기존 AGENTS.md를 무조건 덮어쓰지 않는다.

## 현재 목표

카메라, WASD 이동, Shift 달리기, Space 시선 방향 슬라이딩, 6발 리볼버 조준/발사/회수의 플레이 감각을 검증한다. 그랩패링·강화·웨이브·정식 아트는 명시적 새 요청이 있기 전까지 추가하지 않는다.

## 환경 확인

먼저 ProjectSettings/ProjectVersion.txt, Packages/manifest.json, 기존 씬/스크립트 구조를 읽는다. 사용자 프로젝트의 Unity 버전/렌더 파이프라인/입력 패키지를 확인하기 전에 추정으로 변경하지 않는다. 기존 변경 사항을 보존한다.

기본 구현은 Unity 6, URP 또는 Built-in, 새 Input System을 대상으로 한다. Cinemachine/DOTween/AI Navigation/외부 에셋을 자동 추가하지 않는다. 기본 입력은 PGInput에서 처리한다. 키 리바인딩을 요청받으면 그때 Input Actions 자산으로 옮긴다.

## 바꾸면 안 되는 조작 규칙

- 첫 좌클릭은 조준만. 동일 클릭에 탄환을 발사하지 않는다.
- 조준 상태에서 새로운 좌클릭마다 1발. 버튼 유지로 자동 연사하지 않는다.
- 6발 발사 후 자동 회수. 자동 회수는 조준을 유지한다.
- 우클릭은 조준 해제 + 필드의 모든 탄환 조기 회수. 우클릭을 카메라 회전에 재사용하지 않는다.
- 회수 중에는 발사를 잠그고 이동/슬라이딩은 허용한다.
- 탄수가 아닌 실제 탄환 ID 회수로 장전한다. Ammo + Outstanding은 항상 6이다.
- Space 방향은 누르는 순간의 평면 조준 방향. 입력 이동 벡터를 사용하지 않는다.
- 기본 자유 커서 조준을 유지한다. 일반 숄더뷰는 Tab으로 비교할 수 있다.

## 책임 분리

입력 PGInput, 이동 PGPlayerMotor, 카메라 PGCameraRig, 무기 사이클 PGRevolver, 탄수 PGBulletLedger, 개별 탄환 PGRecallBullet로 분리한다.

흔들림용 카메라 자세를 논리 조준의 다음 프레임 기준으로 사용하지 않는다. CharacterController.Move는 중력을 자동 적용하지 않으므로 중력을 명시적으로 계산한다. 이동과 중력을 중복 적용하지 않는다.

회수 탄은 벽에 막히지 않고 경로의 모든 피해 대상에게 닿는다. 단일 Raycast의 첫 충돌만 사용하지 않는다. 같은 회수 탄과 같은 피해 대상 조합은 1회만 처리한다. 시작점 겹침과 고속 이동 누락을 검사한다. 콜라이더마다 피해를 중복하지 않고 적의 루트 PGDamageable 기준으로 중복을 제거한다.

고정 직선 회수와 현재 플레이어 위치를 따라가는 회수를 혼동하지 않는다. 현재는 매 프레임 목적지를 갱신한다. 사용자가 경로 고정을 요청하지 않았다면 무심코 바꾸지 않는다.

## 작업 범위와 안전

기본 수정 범위는 Assets/PrettyGenocide 및 관련 문서이다. ProjectSettings와 Packages를 통째로 덮어쓰지 않는다. 씬 생성기는 빈 레이어만 추가하고 기존 씬/머티리얼 경로를 덮어쓰지 않는다. 기존 사용자 작업을 삭제하거나 git reset/clean 등으로 없애지 않는다.

한 번에 한 동작을 수정한다. 수정 후 바뀐 파일, 동작 차이, 테스트 결과, 실제 수행하지 못한 테스트를 한국어로 보고한다. Unity를 실행할 수 없으면 'Play Mode 검증 완료'라고 쓰지 않는다.

## 검증

Console 컴파일 오류를 먼저 해결한다. 가능하면 제공된 Run Ammo Ledger Self Tests 메뉴를 실행한다. 그 다음 QA_KO.md의 첫 클릭/전탄/조기 회수/중복 타격/벽/슬라이딩 항목을 Play Mode에서 확인한다. 간단한 텍스트 검사나 코드 리뷰는 실제 컴파일/게임 실행 테스트가 아니다.
