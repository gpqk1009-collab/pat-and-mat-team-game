# Codex에 단계별로 전달할 작업

사용자의 Unity 프로젝트 폴더를 작업 대상으로 열고, 관련 파일의 실제 위치를 알려 준 뒤 아래 프롬프트를 순서대로 사용한다. 한 번에 모든 기능을 다시 만들라고 지시하지 않는다. 이 파일은 프롬프트 모음이며, 여기서 Codex를 실제 실행한 것은 아니다.

## 1. 기존 프로젝트에 소스 키트 통합

```text
프리티 제노사이드 1차 프로토타입을 이 Unity 프로젝트에 통합해 줘.
먼저 ProjectSettings/ProjectVersion.txt, Packages/manifest.json, AGENTS.md,
README_KO.md와 Assets/PrettyGenocide를 읽어 현재 환경을 확인해.

프로젝트 버전/렌더 파이프라인을 변경하거나 기존 씬을 덮어쓰지 마.
Input System의 설치 및 활성화 상태와 코드 컴파일 가능성을 확인해.
PGPrototypeSceneBuilder의 참조 연결, 레이어 마스크, 머티리얼 생성을 점검해.
첫 좌클릭 조준/다음 클릭 발사/전탄 자동 회수/우클릭 조준 해제+회수 규칙을 보존해.

가능한 환경에서 컴파일 및 탄수 장부 테스트를 실행하고,
실행할 수 없으면 미검증이라고 표시해. 수정 파일과 Unity에서 내가 해야 할
조작을 별도로 정리해. 아직 강화/그랩패링/새 패키지는 추가하지 마.
```

## 2. 조준 카메라 감각 조절

```text
카메라와 조작감을 우선 조정해 줘. 다른 시스템 구조는 바꾸지 마.
조준 시작은 강한 숄더 이동과 줌으로 표현하고, 발사는 짧은 반동으로 표현해.
화면 흔들림이 조준 계산에 누적되면 안 돼.
자유 커서와 Tab으로 전환하는 중앙 조준점 모드를 둘 다 유지해.

PGCameraRig의 motionScale, aimTransitionSeconds, normalFov/aimFov,
normalOffset/aimOffset을 조절할 수 있게 유지하고,
약한 연출과 강한 연출의 수치 세트를 제안해.
카메라가 벽에 붙었을 때, 슬라이딩 중, 반복 조준/해제 때를 확인해.
플레이 측정 없이 수치를 확정 밸런스라고 표현하지 마.
```

## 3. 탄환 회수 전투 검증

```text
6발 리볼버의 회수 공격만 검증하고 문제를 고쳐 줘.
탄환 ID 중복 복구, 일곱 번째 발사, 회수 중 발사, 중복 회수 요청,
여러 콜라이더를 가진 적의 중복 피해를 검사해.
벽 너머에도 회수 피해가 전달되며, 고속 이동의 경로 전체를 검사해야 해.
회수 시작 시점에 이미 적 안에 있는 탄환도 놓치면 안 돼.

단순히 시간을 기다려 Ammo=6으로 바꾸지 마.
필요하면 재현용 표적 배치를 별도 새 씬에 추가하되 기존 씬을 덮어쓰지 마.
검증 결과와 실제로 실행하지 않은 항목을 분리해 보고해.
```

## 4. 실제 복셀 캐릭터와 애니메이션 연결

```text
기존 Player 루트의 이동/무기/카메라 코드를 유지하면서 내가 제공한
복셀 캐릭터 모델과 애니메이션을 연결해 줘.
먼저 가져온 모델의 계층과 클립 이름을 실제로 확인해. 없는 클립을 만들었다고 하지 마.
임시 큐브 신체와 visualPose 높이 압축을 정식 애니메이션으로 교체해.
WeaponPivot, Muzzle, RecallSocket 참조를 유지하거나 새 손/무기 소켓에 다시 연결해.
모델이 아직 제공되지 않았다면 기존 모델을 삭제하지 말고 필요한 연결 위치만 정리해.
```
